# Програмування на мові Java

## GUI інтерфейс

### Збірка програми

1. Відкрийте термінал та клонуйте цей репозиторій.
2. Перейд у директорію 'sr1/':
```sh
cd sr1/
```
3. Пропишіть команду збірки:
```sh
javac *.java ../lb5/*.java ../lb6/*.java ../lb7/*.java && java Main.java
```

### Опис та інструкція

- На головній сторінці вказаний автор програми та його фотографія.
- Зліва розміщені всі 7 лабораторних робіт у порядку зростання.
- Відкривши одну із 7 лаб, сторінка буде містити заголовок із назвою та номером лабораторної роботи.
- У вікні ви зможете ввести відповідні дані, або виконати вже заготовлені тести.
