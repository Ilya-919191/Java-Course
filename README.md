# Програмування на мові Java

## GUI інтерфейс (ЛР 1–7)

### Збірка програми

1. Відкрийте термінал та клонуйте цей репозиторій.
2. Перейдіть у директорію `sr1/`:
```sh
cd sr1/
```
3. Пропишіть команду збірки та запуску:
```sh
javac *.java ../lb5/*.java ../lb6/*.java ../lb7/*.java && java Main.java
```

### Опис та інструкція

- На головній сторінці вказаний автор програми та його фотографія.
- Зліва розміщені всі 7 лабораторних робіт у порядку зростання.
- Відкривши одну із 7 лаб, сторінка буде містити заголовок із назвою та номером лабораторної роботи.
- У вікні ви зможете ввести відповідні дані, або виконати вже заготовлені тести.

## GUI інтерфейс (ЛР 8–11)

### Збірка програми

1. Відкрийте термінал та клонуйте цей репозиторій.
2. Перейдіть у кореневу директорію проєкту та переконайтеся, що поруч розміщено JDBC-драйвер (`mysql-connector-j-8.4.0.jar`), а сервер **MySQL** запущено (для роботи ЛР 11).
3. Пропишіть команду збірки та запуску:
```sh
javac -cp ".:mysql-connector-j-8.4.0.jar" sr2/*.java lb11/*.java && java -cp ".:mysql-connector-j-8.4.0.jar" sr2.Main
```

### Опис та інструкція

- На головній сторінці вказаний автор програми
- Зліва розміщені всі 4 лабораторні роботи модуля (ЛР 8–11) у порядку зростання.
- Відкривши одну із 4 лаб, сторінка буде містити заголовок із назвою та номером лабораторної роботи.
- У вікні ви зможете ввести відповідні дані, працювати з файлами або виконувати запити до бази даних.
